# Community pilot / Topluluk denemesi

This is a free open-source alpha, without billing, subscriptions or automatic telemetry. No external user study has been completed. Maintainer automation and synthetic examples are not counted as real users.

1. Start `npm run demo:web` or the restricted public demo. Use the included synthetic scenario.
2. Run the reduction. Expect 16 → 5 steps with the same failure verified in fresh runs; check the included fix and export the evidence.
3. For a real workflow, install the private workbench locally, register only trusted applications and review any capture before executing it.
4. Record installation time, time to first verified reduction, original/retained step counts, whether the evidence helped, and the largest obstacle.
5. Optionally submit **Pilot feedback** through GitHub Issues. Share only counts and a description of behavior. Do not attach source records, credentials, raw HAR files or private capsules.

An initial pilot target is three independent developers successfully installing the project and one reproducing a real failure. These are evaluation targets, not current achievements. Record actual failures too; stars and synthetic success counts do not establish usefulness.

## Türkçe

Bu sürüm ücretsiz açık kaynak alfadır; ödeme, abonelik veya otomatik telemetri içermez. Henüz dış kullanıcılarla pilot tamamlanmadı.

Yerel demo ya da kısıtlı genel demoda 16 → 5 küçültmeyi çalıştır, düzeltmeyi sına ve kanıtı dışa aktar. Gerçek uygulama denemesinde kendi yerel kurulumunu kullan. Kurulum süresini, ilk doğrulanmış sonuca ulaşma süresini, adım sayılarını, işe yarayıp yaramadığını ve en büyük engeli kaydet.

İstersen GitHub Issues içindeki **Pilot feedback / Deneme geri bildirimi** formunu doldur. Kişisel veri, anahtar, ham HAR veya özel kapsül paylaşma. İlk hedef üç bağımsız geliştiricinin kurabilmesi ve en az bir gerçek hatanın tekrarlanmasıdır; bunlar henüz gerçekleşmiş sonuçlar değildir.
